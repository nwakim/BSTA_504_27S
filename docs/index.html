BSTA 504: Introduction to Health Data Science

Spring 2027

Welcome to Health Data Science!

This course introduces the ideas, practices, and applications of health data science in public health and the biomedical sciences. It focuses on the programming and workflow skills that health data work depends on: the command line, version control, reproducible environments, relational databases and SQL, and Python. You’ll practice each skill on real and realistic health data, and use AI coding tools responsibly along the way.

Before the first lesson, apply for GitHub Education, since approval can take several days. The full list of steps is in the Week 1 setup assignment.
